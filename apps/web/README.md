# @checkout/web

Локальная фронтенд-часть задания "Оформление заказа" (Vite + React + TypeScript).

Запуск

```bash
# установить зависимости в монорепо
npm ci

# запустить API (если ещё не запущен)
npm run dev -w @checkout/api

# запустить фронтенд
npm run dev -w @checkout/web
```

Сборка

```bash
npm run build -w @checkout/web
npm run preview -w @checkout/web
```

Конфигурация

- Базовый URL API можно задать через `VITE_API_BASE_URL` (по умолчанию `http://127.0.0.1:4000`).
- Сессия сохраняет `token` в `localStorage` автоматически.

Коротко об устройстве

- `src/api/*` — общий HTTP-клиент и обёртки эндпоинтов. Все запросы проходят через единый `request()`.
- `src/state/cart.tsx` — провайдер корзины: загрузка, обновление позиции, удаление.
- `src/components/*` — основные UI: `Cart`, `Checkout`.
- `src/components/Checkout.tsx` — логика расчётов, создания заказа, попытки оплаты и симуляции тестовых карт. Активная попытка оплаты сохраняется в `localStorage` и возобновляется после перезагрузки.

Производительность — пример

В коде корзины (`CartProvider`) при обновлении позиции используется один запрос `PUT` с последующим `GET /api/cart` для получения актуального состояния — это даёт одно чтение и одну запись на операцию, без дополнительных проходов по массивам в клиенте. UI-компоненты рендерят данные напрямую из `cart` без повторных трансформаций.

Что ещё можно улучшить

- Более тщательная валидация и UX для полей (снижение числа обращений при ошибках). Сейчас реализована базовая проверка имени, email и телефона.
- Полировка интерфейса и адаптивность.
- Тесты пользовательского интерфейса и e2e.
